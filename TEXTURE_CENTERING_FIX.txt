✅ AFTER (CORRECT):
================================================================================

NEW CODE:
    protected void renderBg(GuiGraphics guiGraphics, float partialTick, int mouseX, int mouseY) {
        // Standard Minecraft GUI layout with proper centering
        // Use standard container dimensions for 256x256 textures
        int imageWidth = 176;  // Standard container width for 256px texture
        int imageHeight = 166; // Standard container height for 256px texture
        
        int x = (this.width - imageWidth) / 2;
        int y = (this.height - imageHeight) / 2;
        
        // Blit the texture with proper offset (0,0 is top-left of texture)
        guiGraphics.blit(TEXTURE, x, y, 0, 0, imageWidth, imageHeight);
    }

WHY THIS WORKS:
- Uses standard Minecraft container dimensions (176x166 pixels)
- Centers the texture properly using (screenWidth - textureWidth) / 2
- Matches NeoForge 1.21.1 rendering conventions
- Texture is now perfectly centered on the GUI
