🔧 WHY PLAYER MODEL PARTIALLY GOES INTO BLOCK:
================================================================================

PROBLEM:
- Minecraft's entity collision detection uses a separate system from block collision
- The block's collision shape only affects solid blocks (like walls)
- Entity collision is handled by the world's chunk collision map
- Partial penetration happens because the collision box doesn't match visual size perfectly

TECHNICAL EXPLANATION:
1. Block Collision Shape: Used for player walking through blocks (solid vs air)
2. Entity Collision: Handled by Minecraft's chunk-based collision detection
3. Visual Size vs Collision Size: Must be carefully balanced

WHY PARTIAL PENETRATION HAPPENS:
- Player model is 0.6 blocks tall and 0.6 blocks wide
- If block collision box is too large, player can slip through gaps
- If block collision box is too small, partial penetration occurs
- The collision must be slightly smaller than visual size for proper feel
